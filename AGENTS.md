# Code quality

- Run `bun run check` before finishing.
- Fix the code, not the rules! Don't loosen configuration, and don't add ignore patterns or disable
  comments to silence a check. If you think one earns its place, ask first; if you can't ask, call
  it out in your final message.
- Comment sparingly: only to say what the code can't, like why a non-obvious choice was made. Don't
  narrate what the code does or what you changed; git records the latter.
